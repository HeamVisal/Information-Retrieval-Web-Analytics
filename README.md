## Practical work

### TP1 — Introduction to Information Retrieval & Search Engine Architecture

TP1 covers five topics:

1. Information retrieval systems compared with relational databases.
2. Text preprocessing: parsing, tokenization, stop-word removal, and Porter stemming.
3. Indexing and query processing, including effectiveness and efficiency.
4. Inverted indexes, term frequencies, and Boolean queries.
5. Document scoring and ranking using weighted vectors.

## Using this repository

Start with the lecture slides in `Course/`, consult the reference books for more detail, and open the TP1 template to review the exercises. Use the completed document and PDFs to revisit the worked answers.

PDF files can be opened in a browser or PDF reader. DOCX files can be viewed and edited with Microsoft Word or LibreOffice Writer. No software installation or build process is required to browse the materials.

Keep future lecture materials in `Course/` and add each new practical assignment in its own folder, such as `TP2/`, with its instructions, editable work, and submission files.
